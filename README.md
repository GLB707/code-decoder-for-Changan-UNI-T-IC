# code-decoder-for-Changan-UNI-T-IC
Changan UNI-T Speedometer Diagnostic Code Decoder

This project is a reverse-engineering and diagnostic tool developed for the Changan UNI-T instrument cluster.

The software implements a decoding and recalculation algorithm for the encrypted diagnostic code generated by the vehicle’s instrument cluster. The calculated code can be used to establish communication with compatible diagnostic equipment and perform service and diagnostic operations.

The project also contains a set of CAN bus communication codes related to the vehicle’s instrument cluster and SRS system. These CAN messages can be used to automate specific diagnostic procedures, including the automatic clearing of the Airbag warning indicator after the ignition is switched on.

Main Features

• Encrypted diagnostic code decoding and recalculation.
• Generation of the required diagnostic access code.
• CAN bus communication with the Changan UNI-T instrument cluster.
• Collection and implementation of relevant CAN message identifiers.
• Automated Airbag/SRS warning indicator reset procedure.
• Support for automotive reverse-engineering and diagnostic research.

The project is intended for automotive electronics research, CAN bus analysis, diagnostic tool development, and ECU/instrument-cluster reverse engineering.

Note: CAN identifiers, algorithms, and diagnostic procedures included in this project are specific to the tested Changan UNI-T configuration and may vary between vehicle versions, model years, software revisions, and instrument-cluster firmware.
